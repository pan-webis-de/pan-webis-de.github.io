Task Overview

In the Impostor Generation task, participants build a system that generates impostor documents for authorship verification. Each problem gives the system a document by a known author. The system must produce a set of impostors: texts written in the same domain, genre and topic, but clearly by other authors. Participants submit only the impostor generator, through TIRA. We then plug the generated impostors into a fixed implementation of the Impostors Method and run it on the test dataset. The goal is to generate impostors that let the Impostors Method separate same-author from different-author pairs as reliably as possible.

The task is structured as follows:

  1. Develop an impostor generation system that produces impostor documents for a given input document. To develop and tune your approach, you can use the provided training dataset together with our reference implementation of the Impostors Method, the same one we use for evaluation. You may use any approach, for example prompting or fine-tuning large language models.
  2. Submit your impostor generation system through the TIRA platform.
  3. We will run your system on our test dataset to generate impostors for each verification problem.
  4. We will run our fixed implementation of the Impostors Method on the test problems, using your generated impostors as the comparison set. All other parts of the verification pipeline (features, similarity measure, number of iterations and the decision procedure) are the same for every participant.
  5. We will evaluate authorship verification performance on the resulting decisions. Since the impostors are the only thing that differs between submissions, the score directly reflects how good the impostors are.
